# 测试版 Bug 汇报邮件模板

## 邮件模板

```
收件人：xingchen.li@audi.com.cn
主题：【POMP测试Bug】<一句话描述问题>

Bug描述：<一句话简述问题>

复现步骤：
1. 
2. 
3. 

预期结果：<应该是什么>

实际结果：<实际发生了什么>

截图：<可附截图或录屏>
```

---

## 填写示例 1

```
收件人：dev@example.com
主题：【POMP测试Bug】SC创建页面「提交」按钮点击无反应

Bug描述：SC草稿页面填写完整后，点击「提交」按钮无任何响应。

复现步骤：
1. 登录系统，进入 SC 列表页
2. 点击「新建 SC」，填写 SC 编号、金额、选择申请人
3. 所有必填项填完后，点击底部「提交」按钮

预期结果：弹出提交成功提示，SC 状态变为「待审批」

实际结果：点击按钮后无反应，控制台报错见截图

截图：附件「sc_submit_error.png」
```

## 填写示例 2

```
收件人：dev@example.com
主题：【POMP测试Bug】PO详情页金额显示小数位异常

Bug描述：PO 详情页中，「已分配金额」显示为 10.999999 而非 11.00。

复现步骤：
1. 进入任意 PO 详情页
2. 查看「已分配金额」字段

预期结果：显示为 11.00

实际结果：显示为 10.999999

截图：附件「amount_display_bug.png」
```
