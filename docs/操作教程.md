# POMP 操作教程

> 本教程按角色和工作流程编排，配合操作视频使用。如需查阅字段定义或详细规则，请参阅 [用户使用说明](./用户使用说明.md)。

---

## 快速入门

### 启动

双击桌面 **POMP** 图标，系统自动识别您的 Windows 账号登录。首次使用时自动创建账号（默认角色为"申请人"）。

### 界面

```
┌──────────┬─────────────────────────────────┐
│ 工作台    │                                 │
│ SC       │       主内容区                    │
│ PO       │   （列表 / 详情 / 表单）           │
│ GR       │                                 │
│ 供应商    │                                 │
│ 邮件      │                                 │
│ 系统 *    │                                 │
└──────────┴─────────────────────────────────┘
```

- 左侧导航栏切换模块，底部箭头可收起
- **系统** 仅管理员可见
- **工作台** 展示待办事项概览

### 通用操作

| 操作 | 方式 |
|------|------|
| 搜索 | 列表页顶部搜索框输入关键词（自动搜索） |
| 筛选 | 点击搜索框旁的筛选按钮，按状态/日期/金额组合筛选 |
| 排序 | 点击列表表头切换升序/降序 |
| 分页 | 列表底部切换页码和每页条数 |

## 申请人工作流程

> 申请人是日常业务的主要操作者：创建 SC → 创建 PO → 创建 GR → 完成收货。

### 流程 1: 创建并提交采购申请 (SC)

> **视频教程**: `videos/sc-create.mp4`

**目标**：创建一个新的采购申请并提交进入审批。

**操作步骤**：

1. 点击侧边栏 **SC** → 点击 **新建 SC**
2. 填写基本信息（名称、金额等）→ 点击 **保存草稿**
3. 在 SC 详情页补充完整信息：
   - 点击 **添加供应商**，关联至少一个供应商
   - 可上传附件（合同、审批单等）
4. 确认信息无误后，点击 **提交**
5. 系统校验通过后，SC 状态变为 **经理确认中**，等待管理员处理

> 提交后 SC 不可编辑。如需修改，请先撤销（见流程 5）。

---

### 流程 2: 处理被驳回的 SC

> **视频教程**: `videos/sc-resubmit.mp4`

**目标**：管理员驳回 SC 后，修改信息并重新提交。

**操作步骤**：

1. 在 SC 列表中找到状态为 **已驳回** 的 SC（仅您自己的 SC 会被驳回）
2. 点击进入详情 → 点击 **编辑**，根据驳回原因修改信息
3. 修改完成后点击 **提交**
4. SC 重新进入 **经理确认中**，等待管理员再次审核

---

### 流程 3: 创建采购订单 (PO)

> **视频教程**: `videos/po-create.mp4`

**目标**：在已通过的 SC 下创建采购订单，将预算分配给供应商。

**前提**：目标 SC 处于 **已通过** 状态。

**操作步骤**：

1. 进入目标 SC 的详情页 → 点击 **新建 PO**
2. 在表单中选择供应商（仅显示已关联 SC 的供应商）、填写金额
3. 点击 **保存**
4. 新建的 PO 出现在 SC 详情页的 PO 列表中

> PO 创建后为 **激活中** 状态，可直接创建 GR 收货。PO 金额不能超过 SC 可用余额。

---

### 流程 4: 创建收货确认 (GR)

> **视频教程**: `videos/gr-create.mp4`

**目标**：在激活的 PO 下创建收货确认，核销预算。

**前提**：目标 PO 处于 **激活中** 状态。

**操作步骤**：

1. 进入 SC 详情页 → 找到目标 PO → 点击 **新建 GR**
2. 填写预估金额（必填）、税率（可选，用于自动计算含税合同金额）
3. 点击 **保存**
4. GR 创建后进入 **待审批** 状态（如 PO 已激活且 SC 已通过）

> GR 提交后进入审批流程：管理员确认 → 管理员审批通过 → 预算正式核销。

---

### 流程 5: 撤销误操作

> **视频教程**: `videos/recall.mp4`

**目标**：将已提交的 SC、PO 或 GR 回退到上一个状态。

**SC 撤销**：

| 当前状态 | 撤销后 | 条件 |
|----------|--------|------|
| 经理确认中 | 草稿 | 仅 SC 所有人 |
| 待审批 | 经理确认中 | 仅 SC 所有人 |
| 已通过 | 待审批 | 仅管理员 |

**操作步骤**（以 SC 为例）：

1. 进入 SC 详情页 → 点击 **撤销**
2. 确认操作
3. SC 回退到上一步状态，可重新编辑

**PO 撤销**：激活中 → 草稿（仅 SC 所有人，且无未完成 GR）

**GR 撤销**：经理确认中/待审批 → 草稿（仅 SC 所有人）

---

### 流程 6: 完成 PO / GR

> **视频教程**: `videos/po-gr-finish.mp4`

**完成 PO**：PO 下所有收货完成后，进入 PO 详情页 → 点击 **完成**。PO 状态变为 **已完成**。

**完成 GR**：GR 审批通过后，进入 GR 详情页 → 点击 **完成**。GR 状态变为 **已完成**。

---

### 流程 7: 转让 SC

> **视频教程**: `videos/sc-transfer.mp4`

**目标**：将 SC 的所有权转给其他用户。转让后接收方拥有该 SC 的全部操作权限。

**操作步骤**：

1. 进入 SC 详情页 → 点击 **转让**
2. 选择目标用户（仅显示已启用的用户）
3. 确认转让

## 管理员工作流程

> 管理员负责审批 SC/GR、管理用户、配置系统。管理员也能执行申请人的所有操作。

### 流程 1: 审批 SC

> **视频教程**: `videos/admin-sc-approve.mp4`

SC 审批分两步：**经理确认** → **审批通过/驳回**。

#### 步骤 1: 经理确认

1. 在工作台或 SC 列表中找到状态为 **经理确认中** 的 SC
2. 进入 SC 详情页，核对信息
3. 点击 **确认** → SC 状态变为 **待审批**

#### 步骤 2A: 审批通过

1. 在 SC 列表中筛选 **待审批** 的 SC
2. 进入详情页，核对所有信息
3. 点击 **通过**
4. 如果该 SC 下有草稿 PO，系统会询问是否**级联提交**这些 PO
   - 选择"是"：草稿 PO 自动提交为激活中
   - 选择"否"：草稿 PO 保持草稿状态
5. SC 状态变为 **已通过**，可以创建 PO

#### 步骤 2B: 驳回

1. 进入待审批 SC 的详情页
2. 点击 **驳回**
3. SC 状态变为 **已驳回**，申请人可修改后重新提交

---

### 流程 2: 审批 GR

> **视频教程**: `videos/admin-gr-approve.mp4`

GR 审批分两步：**经理确认** → **审批通过/驳回**。

#### 步骤 1: 经理确认

1. 找到状态为 **经理确认中** 的 GR
2. 进入 GR 详情页，核对信息
3. 点击 **确认** → GR 状态变为 **待审批**

#### 步骤 2A: 审批通过

1. 进入待审批 GR 的详情页 → 点击 **通过**
2. 在弹出的对话框中确认**合同金额 (con_value)**（系统自动填入含税金额，可手动修改）
3. GR 状态变为 **已通过**，预算正式核销

#### 步骤 2B: 驳回

1. 进入待审批 GR 的详情页 → 点击 **驳回**
2. GR 状态变为 **已驳回**

---

### 流程 3: 关闭 SC

> **视频教程**: `videos/admin-sc-finish.mp4`

**目标**：将已完成所有业务的 SC 关闭，防止后续变更。

**前提**：
- SC 下所有 PO 必须为 **已完成** 状态
- SC 下所有 GR 必须为 **已通过** 或 **已取消** 状态

**操作步骤**：

1. 进入已通过 SC 的详情页
2. 确认所有 PO 和 GR 已完结
3. 点击 **关闭**
4. SC 状态变为 **已关闭**，不可再创建新 PO 或变更现有 PO/GR

---

### 流程 4: 管理用户

> **视频教程**: `videos/admin-users.mp4`

**目标**：创建、编辑、启停用系统用户。

**操作步骤**：

1. 点击侧边栏 **系统** → 进入用户管理区域

**创建用户**：点击 **新建用户** → 填写姓名、角色 (Admin/Requester)、Windows 账号 → 保存

**编辑用户**：点击目标用户 → 修改角色等信息 → 保存

**停用用户**：点击 **停用**（停用后无法登录，可随时重新启用）

---

### 流程 5: 配置通知

> **视频教程**: `videos/admin-notification.mp4`

**目标**：设置全局邮件通知规则。

**操作步骤**：

1. 点击侧边栏 **系统 → 通知默认设置**
2. 配置：
   - **管理员收件人**：接收所有通知的管理员邮箱列表
   - **状态变更规则**：哪些状态变更触发邮件、收件人和抄送人
   - **阈值提醒**：预算剩余百分比阈值（如 50%/30%/10%）和时间阈值（如合同到期前 6/3/1 个月）

> 单个 SC 的通知设置可在 SC 详情页单独覆盖全局配置。

---

### 流程 6: 批量导入数据

> **视频教程**: `videos/admin-import.mp4`

**目标**：从 Excel 批量导入 SC / PO / GR 数据。

**操作步骤**：

1. 进入对应模块（SC / PO / GR）列表页
2. 点击 **导入** 按钮
3. 下载模板或选择符合格式的 Excel 文件
4. 预览导入数据，确认无误后点击 **确认导入**

---

## 供应商管理

> **视频教程**: `videos/vendors.mp4`

供应商管理对所有角色开放。

**新增供应商**：侧边栏 **供应商** → **新建** → 填写信息 → 保存

**编辑/停用**：点击供应商行 → 修改信息或点击停用

**批量导入**：供应商列表页 → **导入** → 选择 Excel 文件 → 预览 → 确认导入

> 停用的供应商在新建 PO 时不再显示，不影响历史数据。

## 附录

### A. SC 状态速查

| 状态 | 含义 | 申请人能做什么 | 管理员能做什么 |
|------|------|---------------|---------------|
| 草稿 | 创建中，仅自己可见 | 编辑、提交、删除 | — |
| 经理确认中 | 等待管理员确认 | 撤销 | 确认、撤销 |
| 待审批 | 等待管理员审批 | 撤销 | 通过、驳回、撤销 |
| 已通过 | 审批通过，可建 PO | 创建 PO、撤销 | 关闭、撤销 |
| 已驳回 | 被驳回，需修改 | 编辑、重新提交 | — |
| 已关闭 | 业务完结 | 查看 | 查看 |

### B. GR 状态速查

| 状态 | 含义 | 申请人能做什么 | 管理员能做什么 |
|------|------|---------------|---------------|
| 草稿 | 初始状态 | 编辑、提交、删除 | — |
| 经理确认中 | 等待管理员确认 | 撤销 | 确认、撤销 |
| 待审批 | 等待管理员审批 | 撤销 | 通过、驳回、撤销 |
| 已通过 | 审批通过，预算已核销 | — | — |
| 已驳回 | 被驳回 | 编辑、重新提交 | — |

### C. PO 状态速查

| 状态 | 含义 | 操作 |
|------|------|------|
| 草稿 | SC 为草稿时的初始状态 | 编辑、提交、删除 |
| 激活中 | 已激活，可创建 GR | 创建 GR、完成、撤销 |
| 已完成 | 业务完结 | 撤销 |

### D. 预算计算

- **SC 可用余额** = SC 总金额 − 待审批 GR 预估金额 − 已通过 GR 合同金额
- **PO 可用余额** = PO 金额 − 待审批 GR 预估金额 − 已通过 GR 合同金额

草稿、经理确认中、已取消的 GR 不占用预算。
